🗝️ Configurar Google Maps

Introduce tu clave de Maps JavaScript API solo en la página publicada de VaYa. Se guarda en este navegador. Antes, restríngela en Google Cloud al dominio de GitHub Pages y a Maps JavaScript API y Geocoding API. No uses claves sin restricciones.

Obtener clave ↗
🗺️ Google Maps aparecerá aquí cuando guardes una clave API válida en la versión publicada de VaYa.

El mapa integrado y la búsqueda de direcciones requieren una clave de Google Maps válida y conexión a internet. El cálculo de recorridos utiliza OSRM, un servicio externo independiente (no la Routes API de Google). No incorpora tráfico en vivo ni garantiza la ruta óptima. El botón «Ver pedidos en Google Maps» funciona sin clave API.
